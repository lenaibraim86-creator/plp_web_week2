# My Budget Tracker - Week 2

## What I Built
A static Budget Tracker website that lets users see a form for adding expenses and a table of sample expenses.

## What Each Part Does
- **index.html**: Contains the structure - header with logo, Add Expense form, Expenses table, and YouTube video.
- **style.css**: Contains all styling - table borders, alternating row colors, hover effects, and advanced selectors.
- **Add Expense Form**: Uses a <form> wrapper, <select> dropdown with 5 categories (Food, Transport, Rent, Entertainment, Other), inputs with matching IDs, and a submit button.
- **Expense Table**: Uses <table>, <thead>, <tbody>, <tr>, <th>, <td> with 5 hardcoded sample expenses.
- **Multimedia**: <img> logo near heading and <iframe> YouTube video.
- **Interactive Element**: <details> / <summary> collapsible section explaining how to use the tracker.
